# BACKLOG — приятности вне роадмапа

> Не гарантированный план, а пул улучшений «взять, когда захочется» между этапами
> [ROADMAP.md](ROADMAP.md). Важное (этапы, движки, эталонная валидация) живёт в роадмапе;
> здесь только полирующие вещи. Собран по итогам обзора GitHub-конкурентов 2026-11-13
> (источники — ROADMAP §2.5 и §6).

| Идея | Референс | Суть | Цена |
|---|---|---|---|
| Режимы надёжности p = 10/50/90 % | MeshRF («Best/Typical/Reliable») | переключатель процента времени — в ITM уже есть zT = Φ⁻¹(p), нужен только UI + подпись в результатах | часы |
| Кабельные потери | MeshRF (cable loss calculator) | тип + длина кабеля, коннекторы → строка в бюджете (сейчас потерь фидера нет) | часы |
| Экспорт GeoJSON / KML (+PNG с world file .pgw) | Meshtastic Site Planner | трасса и (после 2.5) покрытие — для QGIS/Google Earth | часы–день |
| Мульти-сайт на карте | Site Planner | несколько передатчиков с независимым вкл/выкл и статистикой каждого (после этапа 2.5) | день |
| Measure tool | Site Planner | расстояние/азимут по двум точкам на карте | часы |
| Каталог-пресеты оборудования | Site Planner, MeshCommunityPlanner | реальные устройства (Tx power, чувствительность, антенна) — входит в одобренный UX-пакет, приоритет у него | день |
| WASM-ITM в воркерах | Site Planner | офлайн-ITM без сервера: компиляция C-исходника NTIA (public domain) в WASM; наш py-порт для этого не годится | недели |
| Импорт живых узлов в план сети | MeshCommunityPlanner | MQTT Meshtastic / map.meshcore.dev → позиции в план сети (после этапа 2.4) | день |
| Переключение подложек + поиск места | Site Planner | dark/streets/topo/satellite + place search на карте | часы |

**Лицензии:** код GPL-проектов (site-planner, pycraf, pyitwom3) не копировать — только
идеи и алгоритмы; MeshRF — MIT; ITM/P.528 от NTIA — public domain.
